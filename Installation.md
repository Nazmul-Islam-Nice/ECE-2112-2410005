Using Homebrew

Logisim-evolution may be available through Homebrew Casks depending on the current repository state. If unavailable or outdated, it is recommended to install the latest version directly from GitHub Releases.

From Github Releases

Logisim-evolution is an open-source digital logic design and simulation software used for designing, testing, and analyzing digital circuits. It provides an intuitive graphical interface for creating combinational and sequential logic circuits and is widely used in digital electronics and computer architecture courses. The latest stable release is Version 4.1.0.

1.⁠ ⁠Downloading and Installing Logisim-evolution

Open the release page: Link

2.⁠ ⁠Download the appropriate installer for your operating system from the latest release.
macOS (Apple Silicon): .dmg file for ARM64
macOS (Intel): .dmg file for x64

3.⁠ ⁠Install the application
Open the downloaded .dmg file.
Drag Logisim-evolution.app into the Applications folder.
Eject the mounted disk image.
4.⁠ ⁠Launch Logisim-evolution
Open Applications and double-click Logisim-evolution, or
Launch it using Spotlight Search (⌘ + Space) and type Logisim-evolution.

If macOS displays a security warning because the application was downloaded from the internet:

Open System Settings → Privacy & Security.
Scroll down to the security warning section.
Click Open Anyway.
